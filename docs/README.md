# docs/

**Purpose:** Human- and agent-readable documentation for the whole system:
architecture, API contracts, and architecture decision records (ADRs).

**Inputs:** Design discussions, contract changes, decisions made during development.
**Outputs:** `architecture.md` (system design), `api-contracts.md` (the single source
of truth for the public HTTP API and internal module interfaces), `decisions/`
(one ADR per decision).

**Does NOT belong here:** Code, generated API docs, user-facing help content,
per-service implementation notes (those live in each service's README).
