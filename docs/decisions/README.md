# docs/decisions/ — Architecture Decision Records (ADRs)

**Purpose:** One file per significant architectural decision, numbered and immutable
once accepted (supersede with a new ADR instead of editing).

**Format:** `NNNN-short-kebab-title.md` (e.g. `0001-use-qwen-vl-for-extraction.md`)
with sections: Context, Decision, Consequences, Status.

**Does NOT belong here:** General documentation (→ `docs/`), API contracts
(→ `docs/api-contracts.md`), meeting notes, code.
