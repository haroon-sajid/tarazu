# sample-data/

**Purpose:** Everything synthetic the project demos and tests against. Two
folders, with different jobs.

| Folder | What it holds | Generated by |
|---|---|---|
| [`fixtures/`](fixtures/) | Hand-written API responses parsed through the real Pydantic models. They are contracts, not scratch data: see [fixtures/README.md](fixtures/README.md). | By hand, kept honest by `backend/tests/test_fixtures.py` |
| `demo-documents/` | Real files to upload: a ledger workbook, a multi-page bank statement PDF, and two invoice PDFs, carrying the documented planted errors. | `python scripts/generate_demo_documents.py` |

The difference matters. `fixtures/` is what the frontend renders when there is
no backend, and what the test suite compares the backend's own output against.
`demo-documents/` is what you upload to run the actual pipeline: extraction,
matching, rules, Benford, and the review queue, end to end.

Both describe the same fictional engagement: `CASE-2026-06-STX`, a June 2026
audit of **Haroon Textiles**, a fictional Karachi textile firm. All amounts are
in PKR and every company name is invented.

**No real client data belongs in this folder, ever.**
